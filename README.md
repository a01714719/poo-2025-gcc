TC1033 Proyecto Demo – Sistema de Membresías de Gimnasio

Contexto:

Un gimnasio que administra distintos tipos de usuarios requiere un sistema para calcular sus pagos mensuales dependiendo de su membresía.
Los usuarios están separados en 3 tipos: premium, estándar y cortesía.

Los usuarios premium pagan una cuota base más una cuota de mantenimiento.

Los usuarios estándar pagan únicamente una cuota base.

Los usuarios de cortesía, aunque también están registrados y usan las instalaciones, no generan pagos, ya que su acceso forma parte de un apoyo o beneficio especial.

Funcionalidad:

El programa permite:

Altas de nuevos usuarios

Cálculo de pagos mensuales para:

usuarios premium

usuarios estándar

usuarios de cortesía

Consideraciones
Compilar con:
